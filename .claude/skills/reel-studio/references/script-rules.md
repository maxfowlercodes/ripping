# Script rules (what `reelkit lint` enforces)
- Format: `# Title`, optional `[style: saas-dark]`, then one beat per line. `//` lines are notes.
- Beat 1 is the hook: ≤ 8 words, speaks to "you", asks a question, or names a number/outcome. Must land in 3 seconds.
- Every line ≤ 14 words, one idea. A new visual every ~3 seconds ⇒ 5–14 beats, 12–45 s total.
- Last beat: ONE action (comment a keyword, follow, save). Comment-keyword CTAs drive reach.
- No filler words. Include at least one concrete number.

## Hook formulas
1. Mistake: "Stop doing X if you want Y."
2. Result-first: "I got N customers from one reel."
3. Contrarian: "Everyone says X. They're wrong."
4. Question: "Why does nobody ____?"
5. Before/after: "From 0 to N in M days. Here's how."

## Skeleton
Hook → Problem (stakes) → Why it happens → Fix step 1 → Fix step 2 → Proof/number → CTA
