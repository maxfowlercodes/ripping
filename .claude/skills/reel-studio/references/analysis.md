# Analysis method
- Views curve: steep D1 then flat = normal. Rising D3→D7 = the algorithm is still testing it (do not touch the post).
- Saves/view and shares/view beat likes/view as quality signals. Comments are driven by the CTA keyword.
- Follower vs non-follower reach: mostly non-followers = discovery content working; mostly followers = it isn't travelling.
- Compare like with like: same length band and CTA type before concluding a hook caused a result.
- Median-based winners (≥ 2× the account's median views) are repurposed; the bottom third are learned from, not deleted.
- Report uncertainty: with < 8 posts, say "too early" rather than inventing a pattern.
